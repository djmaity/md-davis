Command Line Interface
======================

MD DaVis provides the command line tool ``md-davis`` for analysis and
visualization of data from MD simulations.

Getting Help
------------

The list of available commands can be seen with ``--help`` or ``-h``:

.. code-block:: bash

   md-davis --help

which provides the following output:

.. code-block::

   usage: md-davis [-h] [--version] COMMAND ...

   Compare and visualize protein molecular-dynamics simulations.

   positional arguments:
     COMMAND
       collate             Collate data described by TOML input files.
       electrodynamics     Visualize electrostatic field lines in PyMOL.
       electrostatics      Calculate electrostatic potential maps.
       hbond               Parse contacts or H-bonds evaluated by GROMACS.
       landscape           Plot free-energy landscapes from HDF5 data.
       landscape_animate   Plot or animate a landscape trajectory.
       landscape_xvg       Create landscapes from XVG data.
       plot-dipoles         Plot dipole moments from HDF5 files.
       plot_hbond          Plot an H-bond or contact dataframe.
       plot_residue        Plot residue-wise data.
       potential_into_pdb  Write potentials into a PDB file.
       process             Process a GROMACS trajectory.
       residue             Create a residue-data dataframe.
       sequence            Get the amino-acid sequence from a PDB file.
       timeseries          Plot timeseries from HDF5 files.
       xvg                 Plot xmgrace (.xvg) files generated by GROMACS.

   options:
     -h, --help  show this help message and exit
     --version   show program's version number and exit


Similarly, the help for each command can also be accessed with ``--help`` or
``-h``:

.. code-block:: bash

   md-davis <command> -h

For example, ``md-davis xvg -h`` shows the help for
:ref:`xvg <guides/xvg:Plotting Xmgrace (.xvg) Files>` command:

.. code-block::

   usage: md-davis xvg [-h] [-o OUTPUT] [--matplotlib | --plotly]
                       xvg_files [xvg_files ...]

   Plot xmgrace (.xvg) files generated by GROMACS.

   positional arguments:
     xvg_files

   options:
     -h, --help            show this help message and exit
     -o OUTPUT, --output OUTPUT
                           Output filename
     --matplotlib          Use matplotlib instead of plotly for plotting
     --plotly
