Reference
=========

Python Module
-------------

To use MD DaVis as Python module:

.. code:: python

    import md_davis


CLI Reference
-------------

The command-line interface is built with Python's standard-library
``argparse`` module. List the available commands or inspect a command's
options from the terminal:

.. code-block:: console

   $ md-davis --help
   $ md-davis <command> --help
